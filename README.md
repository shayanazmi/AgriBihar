## 🌾 Overview

**AgriBihar** is an open-source agricultural intelligence and climate resilience platform designed to make sixty years of complex agrarian data actionable, visual, and accessible.

Bihar sustains over **104 million people**, with more than **70% of its workforce** engaged in agriculture across the fertile Indo-Gangetic plain. Yet, the region contends with immense climatic volatility:
* **Severe Flood Plains**: Northern Bihar accounts for ~17% of India's total flood-prone area, with 28 districts vulnerable to perennial river basin overflow.
* **Persistent Drought Belts**: Southern tracts face recurring rainfall deficits and seasonal groundwater stress.
* **60 Years of Fragmented Data**: Historic yield, acreage, and meteorological records were previously scattered across government archives and isolated statistical gazettes.

AgriBihar bridges this gap by unifying **six decades (1966–2025)** of validated agricultural records into an instant, client-side, privacy-first web application.

## 🚀 Key Features

### 🗺️ Interactive 38-District Choropleth Atlas
* **Complete District Coverage**: Granular mapping across all 38 modern administrative districts of Bihar using Census Local Government Directory (LGD) boundaries.
* **Statistical Quintile Heatmaps**: Dynamic color ramp classification benchmarked against state and national medians.
* **Seasonal Breakdown**: Comprehensive filtering across all four cropping cycles:
  * **Aghani** (Winter paddy harvest)
  * **Bhadai** (Early autumn crops)
  * **Garma** (Summer crops)
  * **Rabi** (Winter crops including wheat, pulses, and mustard)

### 📈 60-Year Historical Crop Trajectory (1966–2024)
* **Six Decades of Empirical Data**: Traces agricultural shifts from the early Green Revolution to modern hybrid adoptions.
* **National Benchmark Comparison**: Direct overlay comparing Bihar's yield trajectories with all-India averages.
* **Multi-Crop Matrix**: In-depth analytics for 32+ food grains, pulses, oilseeds, and cash crops (Rice, Wheat, Maize, Sugarcane, Jute, Gram, Lentil, Mustard, etc.).

### 🤖 Grounded AI Agricultural Copilot
* **Evidence-First Anomaly Analysis**: When inspecting an anomaly or historic drought year, the AI assistant analyzes the data point within verified historical and climatic parameters.
* **Three-Pillar Structured Output**:
  1. **Documented**: Verified facts backed by empirical data and records.
  2. **Possible Explanations**: Plausible agronomic and meteorological drivers.
  3. **Unknown**: Acknowledgment of data boundaries and unmeasured localized variables.

### 🌐 Native Bilingual Localization (English & हिन्दी)
* Instant, lossless toggle between English and complete Hindi (देवनागरी).
* Localized agrarian terminology (e.g., *अघनी*, *भदई*, *गरमा*, *रबी*, *कृषि विज्ञान केंद्र*).

### 📄 Private Client-Side PDF Export
* Export custom district or crop briefings in one click.
* **100% Client-Side**: Built using locally vendored jsPDF with Subresource Integrity (`sha384`). Zero telemetry, zero external network calls.

## 👓 Analytical Personas

AgriBihar tailors its data density, metrics, and explanations to the user's workflow:

| Mode | Intended User | Focus & Approach | Practical Output |
| :--- | :--- | :--- | :--- |
| **🌾 Field Explorer** | Farmers, PACS leaders, grassroots workers | Clear language, zero jargon, practical agricultural meaning | Actionable questions to ask local Krishi Vigyan Kendras (KVK) and Block Agriculture Offices |
| **🔬 Research Lab** | Agronomists, economists, university researchers | Statistical rigor, standardized $z$-scores, 10-year rolling baselines | Methodological caveats, boundary lineage notes, and falsifiable hypotheses |
| **🏛️ Policy Observatory** | Administrators, policymakers, regional planners | Macro-level yield gaps, MSP alignment, regional disparities | Evidence-driven intervention priorities and public resource planning |

| **Ministry of Agriculture & Farmers Welfare, GoI** | 1966 to 2024 | Statewide Bihar & All-India | 60-year continuous time-series harmonizing historical boundary changes |

## ⚡ Quickstart

AgriBihar is built on pure web standards. You do not need Node.js, Webpack, Vite, or any build step to run it locally.

```zsh
# 1. Clone the repository
git clone https://github.com/shayanazmi/AgriBihar.git
cd AgriBihar

# 2. Start a local HTTP server
python3 -m http.server 8080

# 3. Open in your browser
open http://localhost:8080
```

## 📁 Repository Structure

```text
├── index.html              # Main single-page application (semantic, accessible HTML5)
├── app.js                  # Frontend charting engine, reactive UI, and state logic
├── config.js               # Public configuration file
├── configure.py            # Utility script for syncing config endpoints and CSP
├── fb.js                   # Lightweight frame-busting script (anti-clickjacking)
├── theme-init.js           # Instant dark/light mode initializer (prevents theme flash)
├── assets/
│   └── screenshots/        # High-resolution screenshots and visual assets
├── fonts/                  # Self-hosted variable fonts (Inter & Fraunces, SIL OFL)
├── vendor/                 # Vendored jsPDF 4.2.1 library with SRI verification
└── worker/                 # Serverless AI proxy
    ├── agribihar-ai-worker.js # Hardened edge proxy with schema validation
    └── wrangler.toml          # Worker routing and CORS allowlist
```

## 🚀 One-Click Deployment to GitHub Pages

1. Fork or push this repository to your GitHub account.
2. In your repository, go to **Settings** → **Pages**.
3. Under **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `main`
   * **Folder**: `/ (root)`
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
